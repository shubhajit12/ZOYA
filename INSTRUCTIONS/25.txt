# STEP 3 — PRESERVE ORIGINAL POSE

This is critical.

At controller initialization, capture each controlled bone's original/rest/current rotation.

For Phase 1 control:

```text
spine
chest
neck
head
leftShoulder
rightShoulder
```

Do NOT permanently overwrite the original pose.

Every frame, procedural animation should be calculated as a **small offset from the captured base rotation**.

Conceptually:

```text
finalRotation = baseRotation + proceduralOffset
```

Do NOT accumulate offsets every frame.

BAD:

```text
bone.rotation.x += offset;
```

GOOD:

```text
bone.rotation = baseRotation + currentOffset;
```

Use quaternion-safe composition if the existing implementation requires it.

# STEP 4 — NATURAL PROCEDURAL IDLE

Implement an indefinitely looping idle state.

It must NOT use an animation clip.

It must NOT use keyframe data.

It must NOT require an external animation file.

Use time-based procedural functions such as:

```text
sin()
```

and/or layered low-frequency oscillations with slightly different frequencies/phases.

Avoid obvious synchronized looping.

---

# BODY MOVEMENT

## Spine

Extremely subtle movement.

Purpose:

* tiny posture sway
* natural breathing support

Amplitude must be very small.

## Chest

Primary breathing movement.

Create a slow breathing cycle.

The chest should subtly expand/contract rather than visibly rotate dramatically.

## Neck

Small counter-movement to prevent the head from looking mechanically attached.

## Head

Very subtle independent movement:

* tiny left/right drift
* tiny forward/back or pitch variation
* occasional slow positional/rotational variation

The head must NOT constantly wobble.

It should feel like a person naturally holding their head.

## Shoulders

Very subtle movement synchronized loosely with breathing.

Left and right should NOT be perfectly identical.

Use slight phase/amplitude differences.

---

# IMPORTANT: NO ROBOTIC LOOP

The idle animation should NOT look like:

```text
move left
move right
move left
move right
```

Instead layer several very low-frequency movements.

For example conceptually:

```text
breathing
+
slow posture sway
+
tiny head variation
+
tiny shoulder variation
```

Use different frequencies/phases so the combined movement has natural variation.

Keep everything subtle.

# STEP 5 — SMOOTHING

The animation must remain stable if FPS changes.

Do not depend on a fixed frame rate.
